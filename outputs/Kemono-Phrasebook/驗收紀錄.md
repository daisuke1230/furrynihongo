# MVP 驗收紀錄

本次使用 macOS 上的隔離 Chrome、Playwright 與 Node.js 檢查。瀏覽器測試資料留在暫時環境，交付教材仍為原始 100 句。

| 範圍 | 結果與驗證方式 |
| --- | --- |
| 教材 | 100 句、10 個情境、11 個文法模組；ID 唯一，中文／日文／平假名齊全，分類、文法、例句與相關句 ID 參照通過。沒有重複日文原句。此為資料檢查，尚未經日語教師逐句校訂。 |
| 搜尋 | 中文、片假名、平假名、半形片假名、英文自訂句搜尋通過；情境／文法／收藏篩選及收藏重新載入後保存通過。 |
| 配對 | 4／6／8 組與兩種語言方向通過；300 次抽題檢查未出現重複 ID、同組相同語意群組或重複中文答案；實際點選正確／錯誤答案、完成回合、保存結果、錯題優先補題及正確複習後移除錯題通過。 |
| 文法 | 11 個模組正常顯示；展開例句、連結會話及跳轉文法配對練習通過。內容直接由資料讀取。 |
| 展示 | 390×844、844×390、320×568；標準句子直橫向展示、換行、中文／假名開關、返回與無水平溢出通過。320px 大字深色模式另經截圖檢查。系統全螢幕依瀏覽器能力提供，尚未驗證所有手機實機。 |
| 資料管理 | 新增情境與自訂句、英文搜尋、修改、重新載入保存、刪除確認、備份下載、備份匯回、錯誤 JSON 拒絕、相同 ID 預設保留及明確勾選覆寫通過。 |
| 本機保存 | 收藏、設定、自訂教材、學習紀錄經重新載入與備份還原通過。儲存失敗會提示，不宣稱瀏覽器儲存永久可靠。 |
| 單檔離線 | 直接用 `file://` 開啟，同時將瀏覽器設為離線；100 句顯示、配對、收藏及重新載入通過。無外部 script 或 stylesheet，沒有 HTTP 教材請求。 |
| PWA 離線 | 首次快取全部必要資源後，關閉原分頁，將瀏覽器設為離線，再開新分頁；100 句加上測試自訂句、搜尋、文法、遊戲與設定保存通過。未使用外部資源。 |
| 語音功能邏輯 | 使用可控的 Web Speech API 測試替身，確認日文原句、`ja-JP`、本機語音優先、手選語音、0.75x 語速、播放前取消前段及無語音提示。程式提供 0.75x／1.0x／1.25x、重播與停止。 |
| 語音實際聲音 | 此 headless Chrome 未列出日文語音，因此未驗證實際音訊或離線朗讀。需在使用者手機安裝日文語音後，於飛航模式測試。 |
| 桌面／深色 | 1280×900 桌面與手機大字深色模式經截圖檢查；未發現水平溢出或 JavaScript 頁面錯誤。 |
| 可攜來源 | 從交付內 `source/scripts/build.py` 重新建置成功；交付內資料與邏輯測試通過。建置不需要 npm 或第三方套件。 |

## 建議拿手機完成的最後驗證

1. 從 HTTPS 網址安裝 PWA，確認設定頁顯示必要資源已完整快取。
2. 飛航模式下關閉並重開 App，搜尋、配對並查看文法。
3. 於系統安裝日文語音，確認選單列出；測試三段速度、重播、停止與飛航模式朗讀。
4. 測試該機型的直橫向、加入主畫面與系統全螢幕行為。

GitHub Pages 發布流程會重新建置並驗證教材；教材本身未透過外部 API 取得。`audioUrl` 僅為未來預錄音檔保留欄位。
