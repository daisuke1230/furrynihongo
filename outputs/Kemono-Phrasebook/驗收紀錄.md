## 建議拿手機完成的最後驗證

1. 從 HTTPS 網址安裝 PWA，確認設定頁顯示必要資源已完整快取。
2. 飛航模式下關閉並重開 App，搜尋、配對並查看文法。
3. 於系統安裝日文語音，確認選單列出；測試三段速度、重播、停止與飛航模式朗讀。
4. 測試該機型的直橫向、加入主畫面與系統全螢幕行為。

GitHub Pages 發布流程會重新建置並驗證教材；教材本身未透過外部 API 取得。`audioUrl` 僅為未來預錄音檔保留欄位。
